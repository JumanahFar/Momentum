# Momentum 📈

A modern habit tracking iOS application built with SwiftUI and SwiftData.

Momentum helps users build consistent habits through streak tracking,
daily reminders, insightful statistics, and a clean user experience inspired
by Apple's Human Interface Guidelines.

---

## ✨ Features

- Create and manage daily habits
- Edit and delete habits
- Daily streak tracking
- Habit completion history
- Weekly statistics
- Progress dashboard
- Local notifications
- Clean SwiftUI interface
- Built using MVVM architecture
- Persistent storage using SwiftData

```

├── Models
├── ViewModels
├── Services
├── Components
└── Resources
```
